# GWX-Version-Control

A Git-like Version Control System for ICONICS GraphWorX displays (.gdfx) and Symbol Libraries.

## Project Goal

This project provides version control specifically for GraphWorX engineering files.

Instead of comparing raw XML files, it understands GraphWorX engineering concepts such as:

- Display Objects
- Object Properties
- Dynamics
- Commands
- Symbol Libraries

## Planned Features

- Repository initialization
- Branch support
- Object comparison
- Property comparison
- Dynamic comparison
- Commit history
- Version tracking
- Change reports
- Support for GraphWorX Displays
- Support for Symbol Libraries

## Current Status

Project is under active development.
